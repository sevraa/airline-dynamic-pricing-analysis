# ✈️ Airline Dynamic Pricing Analysis

This project explores the dynamics of airline ticket prices as the
departure date approaches.

The main goal is to investigate how ticket prices are affected by
time-to-departure and remaining seat inventory.

## 🔍 Research Questions

- Do airline fares increase as the departure date approaches?
- How does remaining seat inventory affect ticket prices?
- How can airlines adjust prices as new demand information becomes available?

## 📊 Project Goals

- Simulate airline ticket price data
- Analyze the relationship between price and time-to-departure
- Investigate the effect of remaining seat capacity
- Visualize pricing patterns using Python
- Explore simple mathematical models for dynamic pricing

## 🛠️ Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## 📁 Project Structure

The project will include data simulation, exploratory data analysis,
visualizations, and mathematical modeling.
